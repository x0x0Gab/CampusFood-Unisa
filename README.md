# CampusFood-Unisa

CampusFood è un progetto sviluppato per migliorare la gestione dei servizi di ristorazione presso il campus dell’Università degli Studi di Salerno.
L’obiettivo è ridurre le code in mensa e semplificare il processo di prenotazione dei pasti, rendendo il servizio più efficiente sia per gli studenti che per il personale della mensa.

## Obiettivi principali

- Consentire agli studenti di consultare i menù e prenotare i pasti in anticipo
- Velocizzare le operazioni di accesso alla mensa
- Aiutare il personale a organizzare meglio il servizio in base alle prenotazioni

Il progetto è svolto nell’ambito del corso di Ingegneria del Software (A.A. 2025/2026).
