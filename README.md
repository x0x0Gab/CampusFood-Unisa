# CampusFood-Unisa
CampusFood è un sistema digitale progettato per modernizzare e ottimizzare la gestione dei servizi di ristorazione presso l'Università di Fisciano. L'obiettivo principale della piattaforma è migliorare l'esperienza utente riducendo i tempi di attesa e le code in mensa, oltre a facilitare la pianificazione dei pasti per ottimizzare le risorse.
